# Python 01 — 파이썬의 기본

## 순차 실행

파이썬 코드는 스크립트 파일의 **위에서 아래로, 작성된 순서대로** 한 줄씩 실행된다.

```python
# order.py
print("1번째 줄")
print("2번째 줄")
print("3번째 줄")
```

```text
(base) C:\Users\guest\project> python order.py
1번째 줄
2번째 줄
3번째 줄
```

- 나중에 배우는 조건문(if)·반복문(for, while)·함수 호출도 결국 이 "위→아래 순차 실행"이라는 기본 규칙 위에서 코드의 흐름을 바꾸는 도구일 뿐이다.
- 같은 줄 안에서는 세미콜론(`;`)으로 여러 문장을 이어 쓸 수도 있지만, 가독성을 위해 한 줄에 한 문장을 쓰는 것이 일반적인 스타일이다.

```python
# 세미콜론으로 한 줄에 이어 쓰기 (권장 스타일은 아님)
print("A"); print("B")
```

**정리**: 파이썬 스크립트는 작성한 순서 그대로 위에서 아래로 실행되며, 이후 배우는 모든 제어 흐름 문법(if/for/while/함수)은 이 순차 실행 순서를 조건에 따라 건너뛰거나 반복시키는 역할을 한다.

## print() 함수

**print()**는 괄호 안에 넣은 값을 화면(표준 출력)에 출력하는 파이썬의 기본 함수다.

```python
>>> print("Hello, Python!")
Hello, Python!

>>> print(10)
10

>>> print(3.14)
3.14
```

**여러 값을 한 번에 출력하기**

쉼표로 값을 여러 개 나열하면, 기본적으로 공백 한 칸으로 구분되어 한 줄에 출력된다.

```python
>>> name = "hong"
>>> age = 20
>>> print(name, age)
hong 20
```

**구분자와 줄바꿈 문자 바꾸기**

- `sep` 옵션: 값 사이에 들어갈 구분 문자를 지정한다(기본값은 공백 `" "`).
- `end` 옵션: 출력이 끝난 뒤 붙일 문자를 지정한다(기본값은 줄바꿈 `"\n"`).

```python
>>> print("2026", "09", "10", sep="-")
2026-09-10

>>> print("로딩 중", end="...")
>>> print("완료")
로딩 중...완료
```

- 두 번째 예시처럼 `end` 값을 줄바꿈이 아닌 다른 문자로 바꾸면, 다음 `print()`의 출력이 줄을 바꾸지 않고 바로 이어붙는다.

**정리**: `print()`는 값을 화면에 출력하는 가장 기본적인 함수이며, 쉼표로 여러 값을 나열하거나 `sep`/`end` 옵션으로 구분자와 줄바꿈 방식을 바꿀 수 있다.

## 주석 작성

**주석(comment)**은 파이썬 인터프리터가 실행하지 않고 그냥 건너뛰는 설명용 텍스트다. 코드의 의도를 남기거나, 특정 줄을 일시적으로 실행되지 않게 만들 때 사용한다.

**1) 한 줄 주석 (`#`)**

`#` 뒤에 오는 내용은 그 줄 끝까지 전부 주석으로 처리된다.

```python
# 이 줄 전체가 주석이다
print("이 줄만 실행된다")   # 코드 뒤에 붙는 주석도 가능하다
```

```text
(base) C:\Users\guest\project> python comment_test.py
이 줄만 실행된다
```

**2) 여러 줄 주석 (`'''` 또는 `"""`)**

파이썬에는 전용 블록 주석 문법이 따로 없지만, 작은따옴표 3개(`'''`) 또는 큰따옴표 3개(`"""`)로 문자열을 감싸면 여러 줄을 하나의 문자열로 취급하게 되므로, 이 성질을 이용해 여러 줄을 한 번에 주석처럼 처리하는 방법이 널리 쓰인다.

```python
'''
여기서부터
여기까지는
전부 실행되지 않는 설명 텍스트로 취급된다.
'''
print("이 줄만 실행된다")
```

```text
(base) C:\Users\guest\project> python multiline_comment.py
이 줄만 실행된다
```

- 이 문자열이 변수에 저장되거나 함수/클래스 맨 첫 줄에 놓이면 **독스트링(docstring)**이라는 별도의 문서화용 문자열로 취급되지만, 단순히 코드 중간에 혼자 놓인 경우에는 평가만 되고 버려지는 문자열이라 실질적으로 여러 줄 주석과 같은 효과를 낸다.

**정리**: 한 줄 주석은 `#`, 여러 줄을 한 번에 주석 처리할 때는 `'''`나 `"""`로 감싸는 방법을 관용적으로 사용한다. 주석은 실행에 영향을 주지 않으므로 코드의 의도를 남기거나 디버깅 중 특정 코드를 잠시 비활성화할 때 자유롭게 활용한다.
