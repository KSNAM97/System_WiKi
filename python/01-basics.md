# Python 01 — 파이썬의 기본

## 순차 실행

파이썬 코드는 스크립트 파일의 **위에서 아래로, 작성된 순서대로** 한 줄씩 실행된다.

```python
# order.py
print("1번째 줄")
print("2번째 줄")
print("3번째 줄")
```

```text
(base) C:\Users\guest\project> python order.py
1번째 줄
2번째 줄
3번째 줄
```

- 나중에 배우는 조건문(if)·반복문(for, while)·함수 호출도 결국 이 "위→아래 순차 실행"이라는 기본 규칙 위에서 코드의 흐름을 바꾸는 도구일 뿐이다.
- 같은 줄 안에서는 세미콜론(`;`)으로 여러 문장을 이어 쓸 수도 있지만, 가독성을 위해 한 줄에 한 문장을 쓰는 것이 일반적인 스타일이다.

```python
# 세미콜론으로 한 줄에 이어 쓰기 (권장 스타일은 아님)
print("A"); print("B")
```

**함수 정의와 호출도 순서를 따른다**

함수는 파일 위쪽에 "정의"되어 있더라도, 실제로 실행되는 시점은 그 함수가 "호출"되는 줄이다. 정의만 있고 호출이 없으면 함수 내부 코드는 실행되지 않는다.

```python
# call_order.py
def greet(name):
    print(f"{name}님, 안녕하세요.")

print("프로그램 시작")
greet("홍길동")
print("프로그램 종료")
```

```text
(base) C:\Users\guest\project> python call_order.py
프로그램 시작
홍길동님, 안녕하세요.
프로그램 종료
```

- `def greet(name):` 줄이 먼저 나오지만, 그 안의 `print()`는 파일 3번째 줄이 아니라 `greet("홍길동")`가 실제로 실행되는 시점에 동작한다.
- 즉 함수 "정의"는 "이런 동작을 하는 코드 뭉치가 있다"고 등록만 해둘 뿐이며, 위→아래 순서상 실행이 그 함수의 호출문에 도달했을 때 비로소 내부 코드가 실행된다. 함수 문법 자체는 다음 문서에서 자세히 다룬다.

**한 줄에서 오류가 나면 그 아래 줄은 실행되지 않는다**

순차 실행은 오류가 발생했을 때도 그대로 적용된다. 실행 중이던 줄에서 오류가 나면 프로그램이 그 자리에서 멈추고, 그 아래에 남은 줄은 실행되지 않는다.

```python
# error_stop.py
print("1번째 줄 실행")
print(undefined_var)   # 정의되지 않은 변수 사용 -> 오류 발생
print("3번째 줄 실행")   # 위 줄에서 멈추므로 이 줄은 실행되지 않는다
```

```text
(base) C:\Users\guest\project> python error_stop.py
1번째 줄 실행
Traceback (most recent call last):
  File "error_stop.py", line 2, in <module>
    print(undefined_var)
NameError: name 'undefined_var' is not defined
```

- `NameError`가 발생한 2번째 줄까지만 실행되고, 3번째 줄의 `print()`는 아예 실행되지 않은 채 프로그램이 종료된다.

**정리**: 파이썬 스크립트는 작성한 순서 그대로 위에서 아래로 실행되며, 함수처럼 미리 정의된 코드도 실제로는 호출되는 시점에 실행되고, 중간에 오류가 발생하면 그 지점에서 실행이 멈춰 이후 줄은 실행되지 않는다. 이후 배우는 모든 제어 흐름 문법(if/for/while/함수)은 이 순차 실행 순서를 조건에 따라 건너뛰거나 반복시키는 역할을 한다.

## print() 함수

**print()**는 괄호 안에 넣은 값을 화면(표준 출력)에 출력하는 파이썬의 기본 함수다.

```python
>>> print("Hello, Python!")
Hello, Python!

>>> print(10)
10

>>> print(3.14)
3.14
```

**여러 값을 한 번에 출력하기**

쉼표로 값을 여러 개 나열하면, 기본적으로 공백 한 칸으로 구분되어 한 줄에 출력된다.

```python
>>> name = "hong"
>>> age = 20
>>> print(name, age)
hong 20
```

**구분자와 줄바꿈 문자 바꾸기**

- `sep` 옵션: 값 사이에 들어갈 구분 문자를 지정한다(기본값은 공백 `" "`).
- `end` 옵션: 출력이 끝난 뒤 붙일 문자를 지정한다(기본값은 줄바꿈 `"\n"`).

```python
>>> print("2026", "09", "10", sep="-")
2026-09-10

>>> print("로딩 중", end="...")
>>> print("완료")
로딩 중...완료
```

- 두 번째 예시처럼 `end` 값을 줄바꿈이 아닌 다른 문자로 바꾸면, 다음 `print()`의 출력이 줄을 바꾸지 않고 바로 이어붙는다.
- `sep`과 `end`는 동시에 함께 지정할 수도 있다.

```python
>>> print("a", "b", "c", sep="/", end=" (끝)\n")
a/b/c (끝)
```

**서로 다른 타입의 값을 함께 출력하기**

`print()`는 문자열뿐 아니라 숫자, 불리언, `None` 등 어떤 타입의 값이든 인자로 받아 자동으로 문자열 형태로 바꾸어 출력한다.

```python
>>> print(10, 3.14, True, None, "문자열")
10 3.14 True None 문자열
```

- 정수와 실수는 숫자 그대로, 불리언은 `True`/`False`, `None`은 `None`이라는 글자로 출력된다. 인자로 넘긴 값의 타입과 관계없이 모두 사람이 읽을 수 있는 문자열로 변환되어 출력된다는 점이 `print()`의 기본 동작이다.

**인자 없이 호출하기**

`print()`를 괄호 안에 아무 값도 넣지 않고 호출하면, 빈 줄 하나만 출력된다.

```python
>>> print("첫 줄")
첫 줄
>>> print()
>>> print("다음 줄")
다음 줄
```

**출력 대상을 바꾸는 file 옵션**

`print()`에는 `file` 옵션도 있어서, 기본값인 화면(표준 출력) 대신 다른 대상으로 출력을 돌릴 수 있다. 예를 들어 오류 메세지를 표준 오류(`sys.stderr`)로 보내는 용도로 쓰이는데, 구체적인 활용은 파일/스트림을 다루는 이후 문서에서 다룬다. 지금은 "출력 위치도 옵션으로 바꿀 수 있다" 정도만 알아두면 된다.

**정리**: `print()`는 값을 화면에 출력하는 가장 기본적인 함수이며, 쉼표로 여러 값을 나열하거나 `sep`/`end` 옵션으로 구분자와 줄바꿈 방식을 바꿀 수 있고, 숫자·불리언·`None`처럼 문자열이 아닌 값도 인자로 넘기면 자동으로 문자열로 변환되어 출력되며, 인자 없이 호출하면 빈 줄만 출력하고, `file` 옵션으로 출력 대상 자체를 바꿀 수도 있다.

## 주석 작성

**주석(comment)**은 파이썬 인터프리터가 실행하지 않고 그냥 건너뛰는 설명용 텍스트다. 코드의 의도를 남기거나, 특정 줄을 일시적으로 실행되지 않게 만들 때 사용한다.

**1) 한 줄 주석 (`#`)**

`#` 뒤에 오는 내용은 그 줄 끝까지 전부 주석으로 처리된다.

```python
# 이 줄 전체가 주석이다
print("이 줄만 실행된다")   # 코드 뒤에 붙는 주석도 가능하다
```

```text
(base) C:\Users\guest\project> python comment_test.py
이 줄만 실행된다
```

**2) 여러 줄 주석 (`'''` 또는 `"""`)**

파이썬에는 전용 블록 주석 문법이 따로 없지만, 작은따옴표 3개(`'''`) 또는 큰따옴표 3개(`"""`)로 문자열을 감싸면 여러 줄을 하나의 문자열로 취급하게 되므로, 이 성질을 이용해 여러 줄을 한 번에 주석처럼 처리하는 방법이 널리 쓰인다.

```python
'''
여기서부터
여기까지는
전부 실행되지 않는 설명 텍스트로 취급된다.
'''
print("이 줄만 실행된다")
```

```text
(base) C:\Users\guest\project> python multiline_comment.py
이 줄만 실행된다
```

- 이 문자열이 변수에 저장되거나 함수/클래스 맨 첫 줄에 놓이면 **독스트링(docstring)**이라는 별도의 문서화용 문자열로 취급되지만, 단순히 코드 중간에 혼자 놓인 경우에는 평가만 되고 버려지는 문자열이라 실질적으로 여러 줄 주석과 같은 효과를 낸다.

**3) 독스트링(docstring)과 단순 여러 줄 주석의 차이**

함수나 클래스의 맨 첫 줄에 `"""..."""` 형태의 문자열을 놓으면, 이 문자열은 그냥 버려지는 것이 아니라 그 함수/클래스의 `__doc__` 속성에 저장되어 나중에 다시 꺼내 볼 수 있다. 이것이 코드 중간에 혼자 놓인 여러 줄 문자열과 독스트링의 차이다.

```python
def add(a, b):
    """두 숫자를 더해서 반환한다."""
    return a + b

print(add.__doc__)
```

```text
(base) C:\Users\guest\project> python docstring_test.py
두 숫자를 더해서 반환한다.
```

- 함수/클래스 맨 첫 줄이 아닌 위치에 놓인 `"""..."""`는 `__doc__`에 저장되지 않고 그 자리에서 평가된 뒤 버려지는 일반 문자열일 뿐이므로, 순수하게 "여러 줄 주석" 용도로만 쓰인다.
- 함수 문법 자체는 다음 문서에서 자세히 다루며, 여기서는 독스트링이 "실행되지 않고 버려지는 여러 줄 주석"과 달리 코드에서 다시 조회 가능한 문자열이라는 점만 짚어둔다.

**왜 주석을 다는가**

- 계산식이 복잡하거나 코드만 봐서는 의도가 바로 드러나지 않는 부분 앞에, "왜 이렇게 작성했는지"를 남기는 용도로 주석을 사용한다.
- 반대로 코드만 읽어도 무엇을 하는지 명확한 당연한 내용까지 매 줄 주석으로 남기면 오히려 코드가 지저분해지고 유지보수에 방해가 되므로, 그런 경우는 굳이 주석을 달지 않는 것이 일반적인 실무 관행이다.

**정리**: 한 줄 주석은 `#`, 여러 줄을 한 번에 주석 처리할 때는 `'''`나 `"""`로 감싸는 방법을 관용적으로 사용하며, 같은 `"""..."""` 문자열이라도 함수/클래스의 맨 첫 줄에 놓이면 `__doc__`으로 조회 가능한 독스트링이 되고 그 외의 위치에서는 단순히 버려지는 여러 줄 주석이 된다. 주석은 코드만으로 의도가 드러나지 않는 부분에 이유를 남기는 용도로 쓰고, 당연한 내용까지 남기지 않는 것이 실무에서 권장되는 습관이다.

**EX4) 함수 docstring 작성 후 __doc__로 확인**
- 두 수 중 더 큰 값을 반환하는 간단한 함수를 만들고, 첫 줄에 독스트링을 작성한 뒤 `.__doc__`로 내용을 확인하시오. 함수 문법 자체는 다음 문서에서 본격적으로 다루므로 여기서는 독스트링 확인만 목표로 한다.

```python
# ex04_docstring.py
def bigger(a, b):
    """두 값 중 더 큰 값을 반환한다."""
    if a > b:
        return a
    return b

print(bigger(3, 7))
print(bigger.__doc__)
```

```text
(base) C:\Users\guest\project> python ex04_docstring.py
7
두 값 중 더 큰 값을 반환한다.
```

**정리**: EX1~EX4는 순차 실행 순서, `sep`/`end` 조합, 한 줄·여러 줄 주석으로 코드 비활성화, 함수 독스트링 확인까지 이 문서에서 다룬 세 가지 주제(순차 실행/print()/주석)를 짧은 코드로 직접 확인해보는 예제이며, 함수의 본격적인 문법은 다음 문서에서 이어서 다룬다.
