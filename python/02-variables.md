# Python 02 — 변수와 자료형

## 변수 선언과 재할당

**변수(variable)**는 값에 이름을 붙여 나중에 다시 꺼내 쓸 수 있게 해주는 저장 공간이다. 파이썬은 다른 언어와 달리 변수의 타입을 미리 선언하지 않고, `=` 기호로 값을 대입하는 순간 변수가 만들어진다.

```python
>>> name = "홍길동"
>>> age = 20
>>> print(name, age)
홍길동 20
```

- `변수명 = 값` 형태를 **대입문(assignment statement)**이라고 부른다. 수학의 등호(같다)와 달리, 파이썬의 `=`는 "오른쪽 값을 왼쪽 이름에 저장하라"는 명령이다.
- 같은 변수에 다시 값을 대입하면 이전 값은 사라지고 새 값으로 덮어써진다. 이를 **재할당(reassignment)**이라고 한다.

```python
>>> score = 80
>>> print(score)
80
>>> score = 95
>>> print(score)
95
```

**동시에 여러 변수에 값 대입하기**

```python
>>> x, y, z = 1, 2, 3
>>> print(x, y, z)
1 2 3

>>> a = b = c = 0
>>> print(a, b, c)
0 0 0
```

- `x, y, z = 1, 2, 3`처럼 쉼표로 나열하면 왼쪽 변수 개수와 오른쪽 값 개수가 정확히 일치해야 하며, 각 위치끼리 순서대로 대입된다.
- `a = b = c = 0`처럼 `=`을 연달아 쓰면 세 변수 모두 같은 값 `0`을 가리키게 된다.

**정리**: 변수는 `변수명 = 값` 형태의 대입문으로 만들어지며 타입을 미리 선언할 필요가 없고, 같은 변수에 다시 대입하면 이전 값을 덮어쓰는 재할당이 일어나며, 쉼표로 나열한 다중 대입이나 `=`을 연달아 쓰는 동시 대입도 가능하다.

## 값 복사의 의미론 (참조가 아니다)

숫자·문자열처럼 값이 변하지 않는 **불변(immutable)** 자료형에서는, 변수를 다른 변수에 대입해도 두 변수가 완전히 독립적으로 동작한다.

```python
>>> a = 10
>>> b = a
>>> print(a, b)
10 10

>>> b = 20
>>> print(a, b)
10 20
```

- `b = a`를 실행하면 `b`는 `a`가 가리키던 값 `10`을 그대로 복사해서 가지게 된다.
- 이후 `b`만 `20`으로 바꾸어도 `a`는 여전히 `10`이다. 즉 `a`와 `b`는 대입 이후 서로 영향을 주지 않는 독립된 저장소로 동작한다.

**리스트처럼 변하는(mutable) 자료형은 주의가 필요하다**

리스트, 딕셔너리 같은 **가변(mutable)** 자료형은 사정이 다르다. `b = a`는 "값을 복사"하는 것이 아니라, `a`와 `b`가 **같은 객체를 함께 가리키게** 만든다.

```python
>>> lst_a = [1, 2, 3]
>>> lst_b = lst_a
>>> lst_b.append(4)
>>> print(lst_a)
[1, 2, 3, 4]
>>> print(lst_b)
[1, 2, 3, 4]
```

- `lst_b`를 통해 리스트에 `4`를 추가했을 뿐인데, `lst_a`로 확인해도 똑같이 `4`가 추가되어 있다. `lst_a`와 `lst_b`가 같은 리스트 객체 하나를 함께 가리키고 있기 때문이다.
- 완전히 독립된 복사본이 필요하다면 `list()`나 슬라이싱(`[:]`)으로 새 리스트를 만들어야 한다. 이 내용은 리스트를 본격적으로 다루는 다음다음 문서에서 다시 짚는다.

```python
>>> lst_c = lst_a[:]
>>> lst_c.append(99)
>>> print(lst_a)
[1, 2, 3, 4]
>>> print(lst_c)
[1, 2, 3, 4, 99]
```

**정리**: 정수·실수·문자열 같은 불변 자료형은 변수 대입 시 값이 그대로 복사되어 서로 독립적으로 동작하지만, 리스트·딕셔너리 같은 가변 자료형은 변수 대입이 같은 객체를 가리키는 참조를 공유하는 것이므로 한쪽을 변경하면 다른 쪽에도 영향이 미치며, 독립된 복사본이 필요하면 슬라이싱이나 `list()`로 명시적으로 새 객체를 만들어야 한다.

## 기본 자료형과 type()

파이썬에서 자주 쓰이는 기본 자료형은 다섯 가지다.

| 자료형 | 의미 | 예시 |
|--------|------|------|
| `int` | 정수 | `10`, `-3`, `0` |
| `float` | 실수(소수점) | `3.14`, `-0.5`, `2.0` |
| `str` | 문자열 | `"hello"`, `'안녕'` |
| `bool` | 참/거짓 | `True`, `False` |
| `NoneType` | 값이 없음을 표현 | `None` |

`type()` 함수를 쓰면 어떤 값이 어느 자료형에 속하는지 바로 확인할 수 있다.

```python
>>> type(10)
<class 'int'>
>>> type(3.14)
<class 'float'>
>>> type("hello")
<class 'str'>
>>> type(True)
<class 'bool'>
>>> type(None)
<class 'NoneType'>
```

**int와 float의 구분**

```python
>>> a = 10
>>> b = 10.0
>>> print(type(a), type(b))
<class 'int'> <class 'float'>
```

- 겉보기 값이 같아 보여도 소수점이 붙어 있으면 `float`로 취급된다.
- 정수와 실수를 연산하면 결과는 자동으로 `float`로 승격된다.

```python
>>> print(1 + 2.0)
3.0
```

**bool은 사실 int의 하위 타입이다**

```python
>>> print(True + True)
2
>>> print(True == 1)
True
>>> print(False == 0)
True
```

- 파이썬 내부적으로 `True`는 `1`, `False`는 `0`으로 취급되며, `bool`은 `int`를 상속한 특수한 자료형이다. 그래서 불리언 값끼리 산술 연산도 가능하다.

**None은 "값이 없음"을 나타내는 유일한 값이다**

```python
>>> result = None
>>> print(result)
None
>>> print(type(result))
<class 'NoneType'>
```

- `None`은 `0`이나 빈 문자열 `""`과는 다른, "아직 값이 정해지지 않았다"는 것 자체를 표현하는 특수한 값이다. 함수가 명시적으로 반환값을 지정하지 않을 때 기본으로 돌려주는 값이기도 하며, 이는 함수를 다루는 다음 문서에서 자세히 다룬다.

**정리**: 파이썬의 기본 자료형은 정수 `int`, 실수 `float`, 문자열 `str`, 참/거짓 `bool`, 값 없음을 나타내는 `NoneType` 다섯 가지이며, `type()` 함수로 어떤 값이든 그 자료형을 즉시 확인할 수 있고, `bool`은 내부적으로 `int`의 하위 타입이라 `True`/`False`가 각각 `1`/`0`처럼 동작한다는 점을 알아두면 이후 조건문·반복문을 이해하는 데 도움이 된다.

## 산술 연산자와 연산자 우선순위

파이썬이 지원하는 산술 연산자는 다음과 같다.

| 연산자 | 의미 | 예시 | 결과 |
|--------|------|------|------|
| `+` | 덧셈 | `7 + 3` | `10` |
| `-` | 뺄셈 | `7 - 3` | `4` |
| `*` | 곱셈 | `7 * 3` | `21` |
| `/` | 나눗셈 (항상 float 반환) | `7 / 3` | `2.3333333333333335` |
| `//` | 몫 (버림 나눗셈) | `7 // 3` | `2` |
| `%` | 나머지 | `7 % 3` | `1` |
| `**` | 거듭제곱 | `7 ** 2` | `49` |

```python
>>> print(7 + 3, 7 - 3, 7 * 3)
10 4 21
>>> print(7 / 3)
2.3333333333333335
>>> print(7 // 3, 7 % 3)
2 1
>>> print(7 ** 2)
49
```

**연산자 우선순위**

수학과 마찬가지로 파이썬도 연산자마다 계산 순서(우선순위)가 정해져 있다. 우선순위가 높은 연산자부터 먼저 계산된다.

```text
높음  **                (거듭제곱, 오른쪽에서 왼쪽으로 계산)
      * / // %          (곱셈·나눗셈 계열, 왼쪽에서 오른쪽으로 계산)
낮음  + -                (덧셈·뺄셈 계열, 왼쪽에서 오른쪽으로 계산)
```

```python
>>> print(2 + 3 * 4)
14
>>> print((2 + 3) * 4)
20
>>> print(2 ** 3 ** 2)
512
```

- `2 + 3 * 4`는 곱셈이 덧셈보다 우선순위가 높으므로 `3 * 4`가 먼저 계산되어 `14`가 된다.
- 괄호 `()`는 모든 연산자보다 우선순위가 높으므로, 계산 순서를 명시적으로 지정하고 싶을 때는 괄호를 사용한다.
- `**`는 거듭제곱끼리 이어질 때 오른쪽에서 왼쪽으로 계산되므로, `2 ** 3 ** 2`는 `2 ** (3 ** 2)`, 즉 `2 ** 9 = 512`로 계산된다.

**나눗셈이 항상 float를 반환하는 규칙**

```python
>>> print(10 / 2)
5.0
>>> print(type(10 / 2))
<class 'float'>
```

- 파이썬 3에서 `/` 연산자는 두 정수를 나누어도 결과가 정확히 나누어떨어지는 경우조차 항상 `float`를 반환한다. 정수 나눗셈 결과가 필요하다면 `//`(몫 연산자)를 사용해야 한다.

```python
>>> print(10 // 2)
5
>>> print(type(10 // 2))
<class 'int'>
```

- `//`는 두 피연산자가 모두 `int`일 때만 결과도 `int`이며, 하나라도 `float`가 섞이면 결과 역시 `float`로 나온다.

```python
>>> print(10 // 2.0)
5.0
```

**정리**: 파이썬의 산술 연산자는 `+ - * /` 네 가지 기본 연산에 몫을 구하는 `//`, 나머지를 구하는 `%`, 거듭제곱을 구하는 `**`가 추가되며, 우선순위는 `**` > `* / // %` > `+ -` 순이고 괄호로 순서를 명시할 수 있다. 특히 `/`는 두 정수를 나누더라도 결과가 항상 `float`로 나온다는 점이 다른 언어와 다른 파이썬 특유의 규칙이므로 반드시 기억해야 한다.

## 문자열 결합과 형변환

문자열끼리는 `+` 연산자로 이어붙일 수 있다.

```python
>>> first = "홍"
>>> last = "길동"
>>> print(first + last)
홍길동
```

**문자열과 숫자는 바로 더할 수 없다**

```python
>>> age = 20
>>> print("나이: " + age)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: can only concatenate str (not "int") to str
```

- 파이썬은 서로 다른 자료형끼리 `+` 연산을 자동으로 처리해주지 않는다. 문자열과 숫자를 함께 이어붙이려면 숫자를 먼저 문자열로 **형변환(type casting)**해야 한다.

```python
>>> print("나이: " + str(age))
나이: 20
```

- `str()` 함수는 숫자·불리언 등 어떤 값이든 문자열로 바꿔준다. 반대로 `int()`와 `float()`는 문자열을 각각 정수·실수로 바꿔준다.

```python
>>> print(int("10") + 5)
15
>>> print(float("3.14") + 1)
4.140000000000001
```

**형변환이 실패하는 경우**

```python
>>> print(int("abc"))
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
ValueError: invalid literal for int() with base 10: 'abc'
```

- 숫자로 해석할 수 없는 문자열을 `int()`나 `float()`에 넘기면 `ValueError`가 발생한다.

**f-string으로 형변환 없이 값 끼워넣기**

매번 `str()`을 호출하지 않고도, 문자열 앞에 `f`를 붙이는 **f-string** 문법을 쓰면 중괄호 `{}` 안에 변수를 그대로 넣어 자동으로 문자열로 바꿔 출력할 수 있다.

```python
>>> name = "홍길동"
>>> age = 20
>>> print(f"{name}님의 나이는 {age}세입니다.")
홍길동님의 나이는 20세입니다.
```

- f-string은 `{}` 안에 변수뿐 아니라 계산식도 그대로 넣을 수 있어, `+`로 문자열과 숫자를 억지로 이어붙이는 것보다 훨씬 간결하고 읽기 쉽다.

```python
>>> print(f"내년 나이는 {age + 1}세입니다.")
내년 나이는 21세입니다.
```

**정리**: 문자열끼리는 `+`로 결합할 수 있지만 문자열과 숫자를 함께 결합하려면 `str()`, `int()`, `float()` 같은 형변환 함수로 타입을 맞춰야 하며, 숫자로 해석할 수 없는 문자열을 형변환하면 `ValueError`가 발생한다. 매번 `str()`을 호출하는 대신 f-string(`f"{변수}"`)을 사용하면 형변환 없이도 값을 문자열 안에 바로 끼워 넣을 수 있어 실무에서 더 자주 쓰인다.

## 복합 대입 연산자

같은 변수에 연산 결과를 다시 저장하는 코드는 자주 등장하므로, 파이썬은 이를 축약한 **복합 대입 연산자(compound assignment operator)**를 제공한다.

```python
>>> count = 10
>>> count = count + 1
>>> print(count)
11
```

위 코드는 아래처럼 축약해서 쓸 수 있다.

```python
>>> count = 10
>>> count += 1
>>> print(count)
11
```

| 축약형 | 풀어쓴 형태 |
|--------|-------------|
| `x += n` | `x = x + n` |
| `x -= n` | `x = x - n` |
| `x *= n` | `x = x * n` |
| `x /= n` | `x = x / n` |
| `x //= n` | `x = x // n` |
| `x %= n` | `x = x % n` |
| `x **= n` | `x = x ** n` |

```python
>>> x = 10
>>> x -= 3
>>> print(x)
7
>>> x *= 2
>>> print(x)
14
>>> x //= 4
>>> print(x)
3
>>> x **= 3
>>> print(x)
27
```

- 복합 대입 연산자는 문자열에도 사용할 수 있다. `+=`는 문자열을 이어붙이는 용도로 자주 쓰인다.

```python
>>> msg = "안녕"
>>> msg += "하세요"
>>> print(msg)
안녕하세요
```

**정리**: `x = x 연산자 n` 형태로 반복되는 코드는 `x 연산자= n`으로 줄여 쓸 수 있으며, `+= -= *= /= //= %= **=` 모두 같은 규칙을 따른다. 특히 반복문 안에서 카운터를 증가시키거나 문자열을 누적할 때 복합 대입 연산자를 쓰는 것이 관용적인 파이썬 스타일이다.

## 변수명 규칙

파이썬에서 변수명을 지을 때 지켜야 하는 규칙은 다음과 같다.

**허용되는 문자**

- 영문 대소문자(`a-z`, `A-Z`), 숫자(`0-9`), 밑줄(`_`)만 사용할 수 있다.
- 공백이나 `-`, `!`, `@` 같은 특수문자는 변수명에 쓸 수 없다.

**시작 문자 제한**

- 변수명은 숫자로 시작할 수 없다. 반드시 영문자나 밑줄(`_`)로 시작해야 한다.

```python
>>> 2nd_score = 90
  File "<stdin>", line 1
    2nd_score = 90
     ^
SyntaxError: invalid decimal literal
```

```python
>>> second_score = 90
>>> _hidden = "내부용"
>>> print(second_score, _hidden)
90 내부용
```

**대소문자를 구분한다**

```python
>>> Name = "홍길동"
>>> name = "김철수"
>>> print(Name, name)
홍길동 김철수
```

- `Name`과 `name`은 완전히 다른 변수로 취급된다. 파이썬은 대소문자를 엄격히 구분하는 언어다.

**예약어(keyword)는 변수명으로 쓸 수 없다**

`if`, `for`, `while`, `def`, `class`, `True`, `False`, `None` 같은 파이썬 문법에 이미 쓰이는 단어는 변수명으로 사용할 수 없다.

```python
>>> for = 10
  File "<stdin>", line 1
    for = 10
        ^
SyntaxError: invalid syntax
```

**잘못된 변수명 예시 모음**

```python
1name = "숫자로 시작"        # SyntaxError: 숫자로 시작
my-name = "하이픈 포함"      # SyntaxError: 하이픈은 뺄셈으로 해석됨
class = "예약어"             # SyntaxError: 예약어 사용
my name = "공백 포함"        # SyntaxError: 공백 포함
```

**관용적으로 권장되는 작성 스타일**

파이썬 공식 스타일 가이드(PEP 8)는 변수명에 소문자와 밑줄을 조합하는 **스네이크 케이스(snake_case)**를 권장한다.

```python
>>> user_name = "홍길동"
>>> total_price = 15000
>>> is_valid = True
```

- 문법적으로 강제되는 규칙은 아니지만, 팀 프로젝트나 다른 사람이 읽는 코드에서는 이 스타일을 따르는 것이 일반적이다.

**정리**: 변수명은 영문자·숫자·밑줄만 사용할 수 있고 숫자로 시작할 수 없으며 대소문자를 엄격히 구분하고 예약어는 사용할 수 없다는 네 가지 규칙을 지켜야 하며, 문법적으로 강제되지는 않지만 소문자와 밑줄을 조합한 `snake_case` 스타일을 쓰는 것이 파이썬 커뮤니티의 관용적인 작성 방식이다.

## 실습 예제 (EX1~EX4)

**EX1) 값 복사 vs 참조 공유 확인**
- 정수 변수와 리스트 변수 각각에 대해 대입 후 한쪽을 변경했을 때 다른 쪽에 영향이 있는지 비교하여 출력한다.

```python
# ex01_copy_vs_reference.py
a = 100
b = a
b = 200
print("정수:", a, b)

lst_a = [1, 2, 3]
lst_b = lst_a
lst_b.append(4)
print("리스트:", lst_a, lst_b)
```

```text
(base) C:\Users\guest\project> python ex01_copy_vs_reference.py
정수: 100 200
리스트: [1, 2, 3, 4] [1, 2, 3, 4]
```

- 정수는 `b`만 바뀌고 `a`는 그대로지만, 리스트는 `lst_a`와 `lst_b`가 같은 객체를 가리키므로 둘 다 함께 바뀐다.

**EX2) 원의 넓이·둘레 계산기**
- 반지름을 입력받아(또는 변수로 지정하여) 원의 넓이와 둘레를 계산해 출력한다. 원주율은 `3.14`로 고정한다.

```python
# ex02_circle.py
PI = 3.14
radius = 5

area = PI * radius ** 2
circumference = 2 * PI * radius

print(f"반지름 {radius}인 원의 넓이: {area}")
print(f"반지름 {radius}인 원의 둘레: {circumference}")
```

```text
(base) C:\Users\guest\project> python ex02_circle.py
반지름 5인 원의 넓이: 78.5
반지름 5인 원의 둘레: 31.400000000000002
```

- `radius ** 2`가 곱셈보다 먼저 계산되므로 괄호 없이도 의도한 넓이 공식이 정확히 계산된다.

**EX3) 초 단위 시간을 시:분:초로 변환**
- 임의의 초(seconds) 값을 `//`와 `%`만 사용해 시·분·초로 변환해 출력한다.

```python
# ex03_time_convert.py
total_seconds = 7325

hours = total_seconds // 3600
remainder = total_seconds % 3600
minutes = remainder // 60
seconds = remainder % 60

print(f"{total_seconds}초 = {hours}시간 {minutes}분 {seconds}초")
```

```text
(base) C:\Users\guest\project> python ex03_time_convert.py
7325초 = 2시간 2분 5초
```

**EX4) 잘못된 변수명 고쳐쓰기**
- 아래 잘못된 변수명들을 변수명 규칙에 맞게 고쳐서 실제로 값을 대입하고 출력한다: `1st_place`, `user-name`, `class`.

```python
# ex04_fix_names.py
first_place = "금메달"
user_name = "홍길동"
```


- `1st_place`는 숫자로 시작해서 `first_place`로, `user-name`은 하이픈이 뺄셈으로 해석되어 `user_name`으로, `class`는 예약어라서 `class_name`으로 고쳐야 한다.
